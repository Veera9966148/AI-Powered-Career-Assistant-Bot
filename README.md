# AI-Powered Career Assistant Bot

An AI-powered Telegram Career Assistant built using n8n, Google Gemini AI, and Telegram Bot API.

## Features

- Resume Review Assistance
- Career Guidance
- Interview Preparation
- Job Application Support
- AI-Powered Conversations
- Workflow Automation

## Tech Stack

- n8n
- Google Gemini AI
- Telegram Bot API
- Google Gemini
- Prompt Engineering
- Workflow Automation

## Workflow Architecture

Telegram User
↓
Telegram Trigger
↓
AI Agent
↓
Google Gemini AI
↓
Telegram Response
